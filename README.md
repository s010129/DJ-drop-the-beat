# DJ Drop The Beat 🎧

用鍵盤操作的雙盤 DJ 控制台＋Loop Station，純網頁，不用安裝任何東西。

- **兩台唱盤**：載入自己的音樂（mp3 / wav / m4a / ogg / flac），或一鍵產生示範節拍
- **鍵盤控制**：左手 `W A S D`、右手 `O K L ;`，可倒帶、加速、播放／暫停、Drop
- **刷碟**：用滑鼠轉動唱片或拖曳波形就能 Scratch
- **混音台**：Gain、三段 EQ（左轉到底接近消音）、濾波（低通／高通）、回音、音量推桿、Crossfader
- **Loop Station**：4 軌循環錄音／疊錄，可以錄麥克風或直接錄 DJ 盤的聲音，也能匯入音檔
- **匯出**：錄下整場混音（WAV 無損或壓縮格式）、匯出單一 Loop 軌、匯出所有 Loop 的混音

## 開始使用

不需要建置：

- **直接開啟**：雙擊 `index.html`。（麥克風在部分瀏覽器需要 https 或 localhost 才能使用）
- **本機伺服器**：`npx serve .` 或 `python3 -m http.server`，再開啟 `http://localhost:3000`（或 8000）
- **GitHub Pages**：在 repo 的 Settings → Pages 選擇 `main` 分支的根目錄，就會得到一個 https 網址

建議使用桌機版 Chrome / Edge / Firefox / Safari。按鍵沒反應時，請把輸入法切換成英文。

## 鍵盤對照

| 功能 | 左盤 A | 右盤 B |
| --- | --- | --- |
| **CUE／DROP**：跳回 CUE 點並立刻播放 | `W` | `O` |
| 把目前位置設為 CUE 點 | `Shift` + `W` | `Shift` + `O` |
| **倒帶**（按住） | `A` | `K` |
| **播放／暫停** | `S` | `L` |
| **加速**（按住） | `D` | `;` |
| 回音甩尾（按住，放開留下尾音） | `E` | `I` |
| 暫時放慢／加快 4%（對拍用） | `Shift` + `A` / `D` | `Shift` + `K` / `;` |

| 功能 | 按鍵 |
| --- | --- |
| Loop 軌道 1–4：空軌 → 錄音 → 播放 → 疊錄 → 播放… | `1` `2` `3` `4` |
| 停止／繼續播放該軌 | `Shift` + `1`–`4` |
| 推動 Crossfader（按住） | `←` `→` |
| Crossfader 置中 | `↓` |

`W` / `O` 這個鍵設計成 **DROP**：一按就從 CUE 點（預設是歌曲開頭）立刻開播，適合在換歌時「丟」進下一首。先把唱盤停在想要的位置按 `Shift` + `W` 設好 CUE 點，之後隨時按 `W` 就能 Drop。

## Loop Station 怎麼用

1. 選擇 **錄音來源**：🎤 麥克風、🎚 DJ 盤（直接錄唱盤混出來的聲音）或兩者。
2. 按 `1` 開始錄音，再按一次 `1` 結束——這段長度就是整個 Loop 的長度，並開始循環播放。
3. 再按 `1` 進入 **疊錄**，在同一軌上加新的聲音；再按一次回到播放。按 `↶` 可以復原（再按一次重做）。
4. 按 `2`、`3`、`4` 錄其他軌，長度會自動對齊第一個 Loop（錄滿一圈自動轉為播放）。
5. 匯入的音檔會對齊成 Loop 長度的整數倍；如果沒有其他 Loop，匯入的音檔就決定 Loop 長度。

進階設定：

- **BPM／TAP／A／B**：設定 Loop 的速度，可以手動輸入、跟著點 TAP，或直接抓唱盤偵測到的 BPM。
- **量化**：第一個 Loop 的長度自動對齊到「拍」或「小節」，比較容易錄得剛好。
- **節拍器**：開啟後錄第一個 Loop 會等到下一小節的第一拍才開始；節拍器聲音只送到喇叭，不會被錄進去。
- **延遲補償**：麥克風錄音時往前補償的時間，開啟麥克風時會自動估算，聽起來對不齊可以自己調整。
- **監聽**：把麥克風送到喇叭與混音錄音中（請戴耳機，避免回授）。

## 匯出

- 頂端的 **● 錄製混音**：錄下主輸出（兩台唱盤＋Loop＋監聽中的麥克風），可選 WAV 無損或壓縮格式（WebM / M4A）。
- Loop 軌道上的 **⬇**：把該軌匯出成 WAV。
- **⬇ 匯出 Loop 混音**：把正在播放的所有 Loop 混成一段可以無縫循環的 WAV。

匯出的檔案會列在頁面下方「匯出結果」，可以先試聽再下載。所有處理都在瀏覽器內完成，不會上傳任何檔案。

## 技術說明

- 純 HTML / CSS / JavaScript，沒有外部函式庫或建置步驟（只從 Google Fonts 載入 Orbitron 字型，離線時會自動改用系統字型）。
- 唱盤、Loop Station、錄音器都是 AudioWorklet（`js/processors.js`）：唱盤用三次內插支援任意速率與倒轉，所以倒帶、加速、刷碟和黑膠煞車都很平滑；Loop 以單一取樣精準的時鐘對齊所有軌道。
- 波形與 BPM 偵測（`js/analysis.js`）：onset 自相關＋梳狀比對，估計速度與第一拍位置，用來畫節拍格線、SYNC 與回音時間。

```
index.html        頁面結構
css/style.css     樣式
js/processors.js  AudioWorklet：唱盤、Loop Station、錄音器
js/ui.js          旋鈕、推桿、音量表、WAV 編碼等工具
js/analysis.js    波形峰值、BPM 偵測
js/demo.js        示範節拍合成
js/deck.js        唱盤
js/looper.js      Loop Station 介面
js/app.js         音訊路由、混音台、鍵盤、錄音與匯出
```
