# DJ Drop The Beat 🎧

純網頁的電音工作站，分成三個頁面，**鍵盤和觸控螢幕都能操作**，不用安裝任何東西。

| 頁面 | 檔案 | 內容 |
| --- | --- | --- |
| **DJ 控制台** | `index.html` | 兩台唱盤＋混音台＋4 軌 Loop Station |
| **Loop Station** | `loop.html` | 專門的 6 軌循環錄音機（麥克風／匯入音檔） |
| **打擊墊 PAD** | `pads.html` | 4×4 RGB 力度打擊墊＋16 軌 64 步音序器 |

每一頁上方都有分頁可以切換，也都能錄下整段演出並匯出成 WAV 或壓縮檔。

## 開始使用

不需要建置：

- **直接開啟**：雙擊 `index.html`。（麥克風在部分瀏覽器需要 https 或 localhost 才能使用）
- **本機伺服器**：`npx serve .` 或 `python3 -m http.server`，再開啟 `http://localhost:3000`（或 8000）
- **GitHub Pages**：在 repo 的 Settings → Pages 選擇 `main` 分支的根目錄，就會得到一個 https 網址

建議使用 Chrome / Edge / Firefox / Safari。按鍵沒反應時，請把輸入法切換成英文。

## 1. DJ 控制台（`index.html`）

- **兩台唱盤**：載入自己的音樂（mp3 / wav / m4a / ogg / flac），或一鍵產生示範節拍
- **刷碟**：用滑鼠或手指轉動唱片、拖曳波形就能 Scratch
- **混音台**：Gain、三段 EQ（左轉到底接近消音）、濾波（低通／高通）、回音、音量推桿、Crossfader
- **Loop Station**：4 軌循環錄音／疊錄，可以錄麥克風或直接錄 DJ 盤的聲音

| 功能 | 左盤 A | 右盤 B |
| --- | --- | --- |
| **CUE／DROP**：跳回 CUE 點並立刻播放 | `W` | `O` |
| 把目前位置設為 CUE 點 | `Shift` + `W` | `Shift` + `O` |
| **倒帶**（按住） | `A` | `K` |
| **播放／暫停** | `S` | `L` |
| **加速**（按住） | `D` | `;` |
| 回音甩尾（按住，放開留下尾音） | `E` | `I` |
| 暫時放慢／加快 4%（對拍用） | `Shift` + `A` / `D` | `Shift` + `K` / `;` |

| 功能 | 按鍵 |
| --- | --- |
| Loop 軌道 1–4：空軌 → 錄音 → 播放 → 疊錄 → 播放… | `1` `2` `3` `4` |
| 停止／繼續播放該軌 | `Shift` + `1`–`4` |
| 推動 Crossfader（按住） | `←` `→` |
| Crossfader 置中 | `↓` |

`W` / `O` 設計成 **DROP**：一按就從 CUE 點（預設是歌曲開頭）立刻開播，適合在換歌時「丟」進下一首。

## 2. Loop Station（`loop.html`）

專門的 6 軌循環錄音機，大按鈕適合用手指操作。

1. 按 `1`（或點第一軌的大按鈕）開始錄音，再按一次結束——這段長度就是整個 Loop 的長度，並開始循環播放。
2. 再按一次進入 **疊錄**，在同一軌上加新的聲音；再按回到播放。
3. 按 `2`–`6` 錄其他軌，長度會自動對齊第一個 Loop（錄滿一圈自動轉為播放）。
4. 也可以把音檔拖到軌道上（或按 ⬆）匯入，會對齊成 Loop 長度的整數倍。

| 功能 | 按鍵 |
| --- | --- |
| 錄音 → 播放 → 疊錄 | `1`–`6` |
| 停止／繼續播放該軌 | `Shift` + `1`–`6` |
| 復原／重做第 1–6 軌的上一次疊錄 | `Q` `W` `E` `R` `T` `Y` |
| 全部停止／全部播放 | `Space` |
| 所有 Loop 從頭開始 | `Enter` |
| 節拍器 | `M` |
| TAP 設定 BPM | `P` |

進階設定（兩個 Loop Station 都有）：

- **自動音量**（預設開啟）：新錄的 Loop 會自動放大到適當音量（最多 +20 dB，只放大不縮小），之後在同一軌疊錄也用同一個倍數，層與層之間的大小聲不會跑掉。匯入的音檔維持原本音量。
- **量化**：第一個 Loop 的長度自動對齊到「拍」或「小節」。
- **節拍器**：開啟後錄第一個 Loop 會等到下一小節才開始；節拍器只送到喇叭，不會被錄進去。
- **延遲補償**：麥克風錄音時往前補償的時間，開啟麥克風時會自動估算。
- **監聽**：把麥克風送到喇叭與演出錄音中（請戴耳機，避免回授）。

## 3. 打擊墊 PAD（`pads.html`）

參考 4×4 MIDI 打擊墊控制器設計：16 顆 RGB 發光的力度打擊墊、螢幕、效果旋鈕和步進音序器。

- **3 組合成音色**：Electro 電子鼓、808 經典鼓機、旋律（C 小調五聲：和弦、旋律、貝斯）
- **力度**：Shift + 鍵 = 輕打；觸控可選「觸碰位置」力度（點越上方越大聲），觸控筆會讀取壓力
- **多指同時打**、Hi-Hat 與 Open Hat 互相截斷（choke），和真的鼓一樣
- **Note Repeat 連打**：按住 pad 會照 1/8、1/16、1/32 或三連音速度連續觸發，跟著節拍對齊
- **16 軌 × 64 步音序器**：長度 16／32／48／64 步、Swing、靜音／獨奏、復原
- **即時錄入**：邊播放邊打 pad，自動對齊到最近的 16 分音符
- **Pad 設定**：音量、音高（±12 半音）、聲像、反轉；可以載入音檔或用麥克風錄音取樣到任何一個 pad
- **效果**：Filter（低通／高通）、Delay（3/16 拍）、Reverb、Swing、Volume
- **匯出 Pattern**：算成一段可以無縫循環的 WAV（含回音與殘響的尾巴）
- Pattern 與設定會自動存在瀏覽器裡，重新整理也不會不見

鍵盤 4×4 的位置就是畫面上 pad 的位置：

```
1 2 3 4      和弦／808 貝斯／音效
Q W E R      筒鼓與打擊樂
A S D F      大鼓、小鼓、Hi-Hat、Open Hat
Z X C V      拍手、邊擊、沙鈴、鈸
```

| 功能 | 按鍵 |
| --- | --- |
| 播放／停止音序器 | `Space` |
| 錄入（邊播放邊打 pad） | `Enter` |
| 連打 Note Repeat | `N` |
| 節拍器 | `M` |
| TAP 設定 BPM | `T` |
| BPM ±1（加 Shift 為 ±10） | `↑` `↓` |
| 切換音序器頁 | `←` `→` |

## 匯出

- 每頁頂端的 **● 錄製**：錄下主輸出，可選 WAV 無損或壓縮格式（WebM / M4A）。節拍器不會被錄進去。
- Loop 軌道上的 **⬇**：把該軌匯出成 WAV；**⬇ 匯出 Loop 混音**：把正在播放的 Loop 混成一段可以無縫循環的 WAV。
- 打擊墊的 **⬇ 匯出 Pattern**：把音序器的 Pattern 算成可以無縫循環的 WAV。

匯出的檔案會列在頁面下方「匯出結果」，可以先試聽再下載。所有處理都在瀏覽器內完成，不會上傳任何檔案。

## 技術說明

- 純 HTML / CSS / JavaScript，沒有外部函式庫或建置步驟（只從 Google Fonts 載入 Orbitron 字型，離線時會自動改用系統字型）。
- 唱盤、Loop Station、錄音器都是 AudioWorklet（`js/processors.js`）：唱盤用三次內插支援任意速率與倒轉；Loop 以單一取樣精準的時鐘對齊所有軌道。
- 打擊墊用「提前排程」的音序器（每 25 ms 排下一段 120 ms 內要播的音），節奏穩定不受畫面卡頓影響。
- 所有音色（示範節拍、打擊墊音色組）都由 `js/synth.js` 即時合成，不需要下載任何音檔。

```
index.html / loop.html / pads.html   三個頁面
css/style.css     共用樣式、DJ 與 Loop 頁
css/pads.css      打擊墊頁
js/processors.js  AudioWorklet：唱盤、Loop Station、錄音器
js/core.js        共用音訊核心：主輸出、麥克風、錄製與匯出、鍵盤分派
js/ui.js          旋鈕、推桿、音量表、WAV 編碼等工具
js/synth.js       合成引擎（濾波器、振盪器、包絡）
js/analysis.js    波形峰值、BPM 偵測
js/demo.js        示範節拍
js/deck.js        唱盤
js/looper.js      Loop Station（DJ 頁 4 軌、Loop 頁 6 軌共用）
js/kits.js        打擊墊音色組
js/pads.js        打擊墊、音序器、取樣、Pattern 匯出
js/page-*.js      各頁面的組裝與鍵盤對照
```
