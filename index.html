    DJ DROP THE BEAT

    雙盤 DJ 控制台 + Loop Station。
    用鍵盤倒帶、加速、Drop、刷碟、循環疊錄，最後匯出你的混音。

    左盤 WASD
    右盤 OKL;
    Loop 1234

    鍵盤和觸控都能操作。建議用 Chrome / Edge / Firefox / Safari；若按鍵沒反應，請把輸入法切到英文。

    鍵盤說明

    唱盤 A（左手）
    WDROP：跳回 CUE 點並立刻播放
    Shift+W把目前位置設為 CUE 點
    A倒帶（按住，放開回到原本狀態）
    S播放 ／ 暫停
    D加速（按住）
    E回音甩尾（按住）
    Shift+A / D暫時放慢／加快 4%（對拍用）
    唱盤 B（右手）
    ODROP：跳回 CUE 點並立刻播放
    Shift+O把目前位置設為 CUE 點
    K倒帶（按住）
    L播放 ／ 暫停
    ;加速（按住）
    I回音甩尾（按住）
    Shift+K / ;暫時放慢／加快 4%
    Loop Station 與混音
    1–4空軌：開始錄音 → 播放 → 疊錄 → 播放…
    Shift+1–4停止 ／ 繼續播放該軌
    ← →按住推動 Crossfader
    ↓Crossfader 置中
    滑鼠操作
    唱片按住拖曳轉動 = 刷碟（Scratch）
    放大波形左右拖曳 = 刷碟；總覽波形點一下 = 跳點
    旋鈕／推桿拖曳或滾輪調整，雙擊歸位
    音檔拖放到唱盤或 Loop 軌道即可匯入
